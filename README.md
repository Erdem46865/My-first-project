# My-first-project
Проект для дисциплины введение в проф деятельность

Описание
Разработать консольное приложение для симуляции процесса продажи и бронирования билетов (на самолет или в кинотеатр). Программа должна управлять базой данных рейсов/сеансов, визуализировать схему зала (салона), регистрировать пассажиров и исключать возможность повторной покупки одного и того же места.
Язык разработки: С++
Интерфейс: консольный(CLI)
Парадигма: объектно-ориентированное программирование(ООП)
Структура данных 
Программа строится на взаимодействии четырех ключевых классов:
1. Seat (Место):
	 Поля: int row (ряд), int number (номер), bool isOccupied (занято/свободно), double price (стоимость билета).
     Методы: Конструктор, book() (занять), release() (освободить), getStatus() (вернуть true, если занято).
2. Passenger (Пассажир / Покупатель):
	 Поля: std::string firstName (имя), std::string lastName (фамилия), std::string documentId (номер паспорта или ID).
3. Flight (Рейс / Сеанс):
	 Поля: std::string flightNumber (номер рейса, например, "SU-100"), std::string destination (город назначения), std::vector<std::vector<Seat>> seatingChart (двумерная сетка кресел).
	 Методы: displayMap() — отрисовка зала в консоли, reserveSeat(row, col) — валидация и бронирование.
4. Ticket (Билет):
	 Поля: Уникальный int ticketId, объект Passenger, номер рейса, номер конкретного места.
	 Методы: printTicket() — красивый вывод чека/билета в консоль.
Функционал приложения 
При запуске программа автоматически генерирует 2–3 тестовых рейса со свободными залами (например, 5 рядов по 6 кресел в каждом) и открывает Главное меню:
1. Просмотр доступных рейсов: Вывод списка (Номер рейса  Куда летит  Сколько свободных мест).
2. Показ карты мест: Пользователь выбирает рейс, программа выводит сетку. Свободные места обозначаются как [ . ], занятые — как [ X ]. Ряды и столбцы обязательно пронумерованы для удобства.
3. Бронирование билета:
	 Пользователь вводит номер рейса.
     Вводит ряд и место (например: ряд 2, место 4).
	 Проверка: Если место уже занято или координат не существует, программа выдает предупреждение и возвращает в меню.
	 Если место свободно, запрашиваются данные пассажира (Имя, Фамилия, Паспорт).
     Место переводится в статус isOccupied = true. Создается билет и выводится на экран сообщение: «Успешно! Ваш билет №1234 оформлен».
4. Список купленных билетов: Просмотр всех оформленных в текущей сессии билетов.
5. Выход.
Польза этого проекта
1. Чистый код и ООП: Разделение логики по разным файлам(.h и .cpp).
   Понимание инкапсуляции(private/public)
2. Сложные структуры данных: Управление вложенными контейнерами(std::vector внутри std::vector)
3. Защита от дурака(Валидация): Обработка некорректного ввода пользователя(если вместо цифры ряда ввели букву,  или если указали несуществующее место).
